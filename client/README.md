# Постепенный перенос Netfly на React

React управляет логотипом, обеими панелями навигации,
карточками главной, последними оценками, разделами «Оценённые» и «Буду смотреть», поиском и страницами фильма/персоны.
Остальные разделы и виджет прогресса сериала пока работают на прежнем JS.

## Где что находится

- `App.jsx` — единое React-дерево; порталы размещают страницы в существующих контейнерах HTML.
- `main.jsx` — создаёт один React root и обновляет порталы; предоставляет
  временный адаптер `window.NetflyUI` для текущего приложения.
- `components/Navigation.jsx` — логотип и навигация.
- `components/Home.jsx` — карточки главной и последние оценки.
- `components/Poster.jsx` — небольшой постер с обработкой ошибки загрузки.
- `components/Catalog.jsx` — карточки каталога, ссылки, изображения с повторной загрузкой.
- `pages/Search.jsx` — живой поиск, каталог, страницы результатов и случайный выбор.
- `pages/Movie.jsx`, `pages/Person.jsx` — фильм/сериал и фильмография персоны.
- `pages/Rated.jsx` — весь раздел оценённых фильмов: фильтры, сортировка, статистика, пагинация, раскрытие, актёры, теги и действия карточки.
- `pages/Wish.jsx` — очередь фильмов и сериалов: поиск, переключение вида и типа, порядок, перенос в оценённые, избранное и удаление.
- `api/tmdb.js` — запросы к API каталога и адреса изображений.
- `hooks/useResource.js` — загрузка, ошибки, повтор и отмена устаревших запросов.
- `styles/components.css` — стили перенесённых компонентов.

Данные и запись на сервер пока принадлежат существующему приложению.
Оно передаёт React снимки данных и функцию перехода `goTo`.
В контейнеры `brandRoot`, `nav`, `mobileNav`, `homeDashboard`,
`recentWrap`, `searchRoot`, `moviePageContent` и `items` нельзя вставлять содержимое через innerHTML/appendChild:
их дочерние элементы принадлежат React.

## Разработка и сборка

`npm start` — сначала собирает React, затем запускает полный сервер.
`npm run local` — собирает React и запускает только статические файлы.
`npm run client:watch` — отдельный процесс пересборки React при изменениях;
после изменения обновите страницу браузера.
`npm run test:react` — сборка и проверка совместной работы React/старого JS
в DOM-среде с тестовыми API. Это не проверка вёрстки реальным браузером.

esbuild собирает JS и CSS в `public/assets/`. Результат не коммитится.
Netlify собирает эти файлы через `npm run build` и продолжает публиковать
`public/`. Переменные сервера не включаются в клиентский пакет.

## Следующие этапы

1. Вынести модель библиотеки и сохранение в модули с единым источником состояния.
2. Перенести прогресс сериалов и календарь серий.
3. Вынести авторизацию, профиль и настройки.
4. Передать React всё дерево приложения и маршрутизацию; удалить адаптер,
   старые DOM-обработчики и inline-скрипт только после переноса потребителей.

До завершения миграции используется текущий History API: новый роутер
не должен одновременно перехватывать переходы. Серверный API, cookies,
схема базы, адреса страниц и ключи локального хранения сохраняются.

Поиск сохраняет введённые параметры и страницу при возврате из фильма.
При уходе со страницы запросы отменяются, трейлер размонтируется.
Названия/имена ищутся через multi-search; фильтры жанра/года/типа относятся
к каталогу без поисковой строки. Режиссёр и актёр используются случайным
выбором — эти ограничения существующего API показаны рядом с фильтрами.
Передача в старую форму оценки/очередь проходит через `applyTmdbMovie`.
